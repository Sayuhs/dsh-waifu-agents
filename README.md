# dsh-waifu-agents

![dsh-waifu-agents](icon.png)

**把一个目录里的每个 `.md` 变成能对话的 agent 人设。** 建、改、导入导出、换默认、升级——全在 **设置 → 插件** 里点，不用敲命令。

## 它能做什么

| 能力 | 一句话 |
| --- | --- |
| **轮次级换人** | 会话开到一半，`/waifu-change 名字` 就**从下一轮**开始由她回答——不用新开会话，不用重启 |
| **两层人设，互不干扰** | **会话级**：这一个会话用谁；**全局默认**：以后新建的会话用谁 |
| **面板就是全部** | 新建 / 编辑 / 改名 / 分组 / 排序 / 搜正文 / 批量隐藏 / 导入导出，一个标签页里做完 |
| **公共条款只写一次** | 共用框架放进 `_common.md`，每篇只写她自己那段；改一次，所有人一起变 |
| **顺序永远对** | 自定义人设一定排在四个内置模式（standard / ptc / minimal / cordis）**下面**，内部顺序可拖拽 |
| **面板内自升级** | 面板里检查版本 → 确认 → **进度窗**告诉你 pnpm 在干什么 → 装完明确说「重启 DSH 生效」 |
| **改完当场生效** | 换默认立刻反映到新任务页，连屏幕上那个还没开口的空会话也一起换 |

## 三条命令

会话已经开着、想换人的时候用：

| 命令 | 作用 |
| --- | --- |
| `/waifu-change` | **不带参数**：弹出选择器（可搜索、按分组、当前那位打勾）。**带名字**：`/waifu-change 大肥鱼` 直接切，名字可以只打前几个字 |
| `/waifu-current` | 一句话告诉你这个会话现在是谁在回答 |
| `/waifu-reset` | 清掉本会话的覆盖，回到它原本挂载的那一篇 |

> **「轮次级」是什么意思**：换人**从下一轮开始生效**，你正在打的那一句不动，已经发出去的回答也不会重写。但**下一轮**的请求会带上新人设，并且额外附一句运行时的身份确认，让模型彻底放下上一位——只改系统提示词是不够的。细节见[第四节](#四会话开到一半想换人三条命令)。

## 两件容易混的事

|  | 管的是 | 在哪改 | 什么时候生效 |
| --- | --- | --- | --- |
| **会话级** | **这一个**会话用谁 | 新任务页顶部的 preset 选择器，或会话里用命令 | 开口前随时可换；一旦发出第一条消息就锁定，改用命令 |
| **全局默认** | **以后新建**的会话用谁 | 插件面板每行右边的开关，或 设置 → Agent Presets | 改完立刻，连屏幕上那个还没开口的空会话也一起换 |

这两条是**两件不同的事**，也是这个插件最常被搞混的地方。第二节逐条展开。

| | 做什么 |

## 一、安装与启用

设置 → 插件 → **添加插件**，输入包名：

```
dsh-waifu-agents
```

想锁定版本就写精确版本号（升级时**必须**这么写，见第八节）：

```
dsh-waifu-agents@0.1.0
```

装完**要在卡片上点「立即启用」**，否则重启后一个人设都不会出现——**安装和启用是两件事**。

## 二、谁在跟你说话

### ① 这个会话用谁 —— 会话级，说第一句话之前随时可换

- 开一个**新任务**（还没发过消息），页面上方那个 preset 名字**可以点开**，选中她。
- 选完立刻挂在这个会话上，**从第一句话起生效**，不用重启，也不用碰插件面板。
- 一旦发出**第一条消息**，这个会话的人设就**锁定**了。想换，开一个新任务。
- 会话标题栏有个**只读**标签，告诉你它正在用谁。

### ② 以后新会话默认用谁 —— 默认值

面板里每行右边的**开关**：打开 = 她成为新会话的默认。**同一时间只有一个**；也允许**全部关掉**，那就不指定，新会话回落到 profile 自己的默认。

它和 **设置 → Agent Presets** 里的「设为新任务默认」是**同一条设置**，改哪边都一样。

四个值得知道的细节：

| 细节 | 说明 |
| --- | --- |
| **改完当场通知平台** | 这条写入走平台自己那条路径（和 Agent Presets 页面同一个调用），所以新任务页顶部的选择器**立刻**跟上。 |
| **连你已经打开的那个空会话一起换** | 只写「新会话默认」其实只管**之后新建**的会话；已经摆在屏幕上、还没开口的那个，人设是**创建那一刻**定下的，不会自己回头。插件会把**还跟着旧默认的**空会话一起挪过去——你特意在某个空会话上选过别的人设，不会被顺手改掉。已经聊过的会话平台会直接拒绝（`agent-preset/locked`），插件不会硬改。 |
| **开关在读回来确认过之后才变绿** | 写进 profile 到平台真的认这行之间有一小段延迟（Loader 要重新激活那一行），插件会轮询到平台的值跟上再报成功。看到「写进去了，但读回来还是「…」」，说明这条设置被别处的 patch 覆盖了（`cordis.patch.yml`、home patch，或命令行 `--patch`）——插件会把它说出来，而不是假装改好了。 |
| **边框当场落到新行** | 切默认时高亮必须**当次**换行，不能留在上一位选过的行上。默认指不到人时（文件改名、删掉、组装不出来）设置页会直接提示，因为平台这时会**悄悄**回落，新会话看起来就像「没记住我设的默认」。 |

### ③ 前提：把「显示代码工作视图」打开

设置 → **通用** → **显示代码工作视图**。关掉它，新任务页上那个选择器就不见了。这是 DSH 自己的开关。

### ④ 会话开到一半想换人：三条命令

| 命令 | 作用 |
| --- | --- |
| `/waifu-change` | **不带参数**：弹出选择器（可搜索、按分组、当前那位打勾）。**带名字**：`/waifu-change 大肥鱼` 直接切；名字可以只打前几个字，唯一就能对上，歧义会列出候选 |
| `/waifu-current` | 一句话告诉你这个会话现在是谁在回答 |
| `/waifu-reset` | 清掉本会话的覆盖，回到它原本挂载的那一篇 |

**怎么生效**

- **从下一轮开始**，当前这句不动。
- 换人时喂给模型的那段人设**前后各有一行**：开头是**「人设已切换」**（点名作废之前的身份），结尾是**「本轮身份 · 最后确认」**。不想要这些行，把插件配置里的 `switchNotice` 设成 `false`。
- **真正让切换落地的是另一条通道**：换过人之后，每一次请求的最后会多出一句**「本轮身份 · 运行时确认」**（作为独立消息跟在你的提问后面）。它不是人设正文的一部分，而是平台自己的「运行时快照」通道——那句话本身带着「本条快照作废更早的快照」的语义，而且只在身份**变了**的时候才出现。为什么非要有它：光改系统提示词是不够的，模型会拿**自己前几轮以旧身份说过的话**当锚，越问越犟（实测连续三次切换、三次请求都带对了新人设，模型仍然坚持第一位）。没换过的会话不会多这一句。想关掉它，把 `identityReminder` 设成 `false`。

**几个细节**

- **重复切到同一个人不会假装生效**：打的是这个会话**已经在用**的那位时，回答是「本来就是 X · 没有改动」——提示词一个字都没变，平台不会重送，模型也不会被重新锚定，那一刻说「已切换」是假话。想真的重新锚定，先切到别人，再切回来。
- **打 `@` 也能挑**：候选菜单里多一组人设，选中就把 `/waifu-change 名字` 填进输入框，回车即可。
- **只列能用的人设**：你选中的那篇如果组装不出来，**不会替换**，这一轮仍然用原来那位。
- **`/waifu-reset` 也算换人**：回落之后这一轮照样会收到「人设已切换」和那句运行时身份确认，所以模型不会继续用刚被 reset 掉的那位说话。（早先的版本会——它把「换过人」判成「这个会话被外挂覆盖过」，而 reset 回落的是会话挂载的那一位，于是刚好漏掉。）
- **会话顶上那个标签会跟着变**。以前它一直显示这个会话**创建时**挂的那一位，换了人也不动（那是平台的行为：给已经开过口的会话换挂载，等于把整套 preset 连同工具一起重装，平台会直接拒绝）。插件现在用平台自己的那条通道把标签挪过去，只动标签、不动正在跑的插件树——所以标签说的和模型听到的终于一致了。
- **一个副作用要知道**：标签也是**会话恢复时**用来决定挂载谁的。所以换过人之后，下次打开 DSH 恢复这个会话，它会真的按新人设装配（工具集也跟着换）。如果你不希望这样，把插件配置里的 `syncSessionChip` 设成 `false`，标签就保持原样不动。

### ⑤ 顺序和分组

- 名册按每篇文件的 `order:` 排，组内也是。
- 填了「分组」就按组折叠显示；没填的归到「未分组」。
- **默认人设所在的那一组会自动展开并滚到她**。
- 想手动排序：见第四节（要先在设置里打开开关）。

## 三、面板

面板 = 设置 → 插件 → 卡片 **dsh-waifu-agents** → 标签页 **waifu-agents**。分**两个分段**：「**人设**」是名册，「**设置**」是运维。

**工具条**

| 按钮 | 作用 |
| --- | --- |
| 搜索框 | 按名字 / 简述 / 分组 / id 筛选；打 **2 个字以上**还会搜正文，命中单列在「正文命中」里，标明来自**骨架**还是**正文** |
| 新增 | 在列表最上面开一张空卡片 |
| 导入 md | 选一个 `.md` 存进目录（同名会报错，不覆盖） |
| 导出全部 | 逐条下载，每条之间停一小会儿，**别急着关页面** |
| 下载出厂人设 | 下载包内那份出厂人设，照着改，再用「导入 md」导回来 |
| 批量 | 勾选模式：全选 / 隐藏选中 / 导出选中 / 取消选择 |
| 拖拽排序 | **默认关闭**。打开后整行都能拖，行内的展开、开关、导出、归档会锁住防误触。存在浏览器本地 |
| 刷新 | 重扫并重新注册。手动放进目录的文件、内容改过的篇目都要按一次 |

**每一行**

| 控件 | 作用 |
| --- | --- |
| ↕ | 拖拽手柄。在工具条打开「**拖拽排序**」后出现；**整行都能拖**，拖到另一行上即保存顺序 |
| ▸ / ▾ | 展开 / 收起她的编辑器。**只有这个按钮会展开**，点名字不会——免得误触 |
| 开关 | 她是不是**新会话的默认**。和 设置 → Agent Presets 是同一个开关 |
| 下载图标 | 导出这一条 `.md` |
| 归档图标 | 点一下**弹确认窗**，勾选后才能确认：文件归档成 `<id>.md.off`，**正文不删** |
| 勾选框 | 只在「批量」模式下出现 |

**设置页**（左边描述、右边操作）

| 行 | 作用 |
| --- | --- |
| 人设目录 | 填路径 → 保存：插件会重启一次并重扫。灰着 = 路径没改 |
| 目录来源 | 目录是从哪挑出来的 |
| 公共骨架 | 有没有骨架、文件在哪；按钮**就地展开编辑器** |
| 已隐藏 | 展开后逐条「取消隐藏」 |
| 新会话默认用谁 | 当前默认是谁 + 「关掉（谁都不指定）」；默认指不到人时在这一行下面直接报错 |
| 分页 | 每页 N 条，默认关闭。存在浏览器本地 |
| 彻底清理 | 把本插件留在文件系统里的东西一次清掉（会话覆盖记录、全局默认指向）；右边开关打开会**连人设目录一起删**。弹窗勾选后才执行 |
| 插件版本 | 当前版本 + 更新按钮。确认后原地换成**进度窗**，装完要你自己点「关闭」（见第八节） |
| 诊断 | 名册里「默认」是从哪个面读出来的、有没有错；另有一行告诉你这个默认**解不解得开**（`defaultResolves`） |

## 四、日常操作

- **新建**：点「新增」→ 填「名字」和正文（简述、分组可留空）→ **离开输入框自动保存**。什么都没填就点到别处，空卡片会被丢掉。目录里有骨架时，新建会**自动套上**它。
- **编辑**：点任意一行展开 → 改完**离开输入框自动保存**（切到别的行、离开标签页，最后一次改动都不会丢）。正文上方可切「编辑 / 预览」，预览渲染的是**组装之后的成品**。
- **改名**：直接改「名字」，**文件名自动跟着变**（转小写、空格标点折成 `-`，中文原样保留；撞名加 `-2`）。
- **导出**：单条用行尾的**下载图标**；全部用工具条的「导出全部」。
- **隐藏 / 取消隐藏（不是删除）**：归档图标 → 弹窗确认 → 文件变成 `<id>.md.off`。**取消隐藏**在「设置 → 已隐藏」里点一下；重复隐藏产生的 `.md.off.2`、`.3` 也在那儿。
- **调整顺序**：在「**人设**」工具条点「**拖拽排序**」（默认关着，防误操作）→ 整行可拖，拖到另一行上即保存——写进文件的 `order:`，重启后还在。开着的时候行内的按钮和展开会锁住，关掉立刻恢复。批量模式下始终不能拖。
- **分组**：在编辑器里填「分组」，名册就按组折叠。
- **搜索**：名字 / 简述 / 分组 / id 是本地筛选；正文搜索走 Host，只回片段。
- **正文里不要写 `{{…}}`**：平台的提示词渲染**只认 `{{provider}}`、`{{model}}`、`{{cwd}}`**，写别的会让整份系统提示词渲染失败、**会话直接起不来**。面板保存前会拦，Host 还会再拦一次。要写占位符请用 `[[name]]` / `[[body]]`。

## 五、什么时候生效

**新的一轮生效，已经发出去的那句不生效。**

- 改完人设 → 新开一个任务立刻生效；**手头这个会话仍然用旧的**。
- 命令（`/waifu-change` 等）**从下一轮开始生效**。
- **改骨架 → 所有已经开着的人设会话，下一轮都会跟着变**（它们每轮都按当前骨架重新组装）。这是唯一不遵守「只对新会话生效」的东西，骨架编辑器里也写着这句。
- 保存本身是即时的：名册立刻变。**升级插件**要重启 DSH；**换目录**会让插件自己重启一次。

**改完正文或骨架要按「刷新」**：手动放进目录的文件、内容变过的篇目，都要按一次才会重新注册。

**用外部编辑器改过同一个文件？** 面板保存时会带上「我读到的那一版」的指纹；对不上就**拒绝写入**，而不是覆盖对方。重开这一行载入最新内容再合并。每次覆盖前旧内容留一份 `<id>.md.bak`，写入走「临时文件 + rename」，不会有半截文件。

## 六、人设文件与公共骨架

```markdown
---
name: 显示名
order: 20
description: 一句话简介
group: 组名
template: _common.md
---

正文：这个人**独有**的那部分。
```

- 开头这几行**都可以省**；第一个 `---` 之后的一切都是正文。
- **保留名**：`README.md`、`_template.json`、`_common.md`——扫描时跳过，也占不到这些 id。
- **`template: _common.md`**：正文插进骨架里 `[[body]]` 的位置，骨架里的 `[[name]]` 换成显示名。**不写这行就整篇注入**（老文件原样可用）。
- `group:` 只影响面板视图，不影响注册。`order` 决定顺序。
- **`order` 是插件内部的局部序号，注册时会整体加上 10000**：平台把四个内置模式（standard 1 / ptc 2 / minimal 3 / cordis 4）和人设放在**同一个**排序键上，直接把你写的 1、2、3 交出去就会和内置互相穿插（实测会出现 `后藤一里 / standard / 大肥鱼 / ptc / …`）。加偏移之后，无论你写多小，自定义人设一定排在内置四个**下面**。文件里存的一直是你自己那个号，拖拽排序也只改这一行。
- 通过面板保存 / 导入会**规范化文件**：只保留 `name`、`order`、`description`、`group`、`template` 五行（空的不写），正文去掉首尾空白，换行统一 LF。想留别的东西请放进正文。
- front matter 是**扁平子集**：一行一个键，值里有 `:` 没问题（按第一个 `:` 切），不需要引号。保存前会校验并指出行号。

**公共骨架**（`_common.md`，放在同一个人设目录里）：

```markdown
现在起，你是「[[name]]」。

[[body]]

【硬性边界】
- 表演层可以自由发挥；代码、路径、行号、命令参数必须一字不差。
```

- 必须**恰好一个** `[[body]]`；没有或有两个，保存都会被拒。
- `[[name]]` 可以出现任意次。
- 骨架里同样不许出现非法的 `{{…}}`。
- **改骨架会立刻影响所有开着的人设会话**（见第五节）。

## 七、人设放在哪

- **自动挑选**，顺序是：面板里指定的目录 → `$DSH_HOME/personas`（通常是 `C:\Users\你\.dsh\personas`）→ 系统用户目录下的 `.dsh/personas` → 插件自带的出厂目录。前两个都不存在时，插件会用出厂人设把目录建出来。
- 看当前用的是哪个：设置里的「**目录来源**」那一行。
- 换地方：路径填进「人设目录」→ 保存，插件会自己重启一次。
- **目录在插件包内时是只读的**：插件升级会整包替换它，写进去的人设会跟着没。看到这个提示就把目录换到包外。
- 目录在**你自己的用户目录**里，所以卸载插件**不会删掉任何人设**；重装后原样回来。
- **插件在包外只写这一个目录**：你的 `.md`，加上一份 `overrides.json`（记录「哪个会话指定了谁」）。除此之外不往任何别处写文件。

## 八、更新插件

- 面板**顶部**有新版时会多一条「有新版本 X · 当前 Y」+「查看」；
- 「**设置**」里的**版本行**也有一个按钮。

两条都打开**同一个确认窗**：

1. 窗里写着当前版本、要装到哪个版本、这次会做什么；
2. **勾选**「我知道这会安装新版本，并且需要重启 DSH」才能按确认——确认键在勾选前是灰的；
3. 确认后**窗口不会关**，原地换成**进度窗**（见下）；
4. 装完**必须重启 DSH**。

没有新版时，那个按钮是「**已是最新版本**」——它是状态，点一下等于重新检查。

### 进度窗

点确认之后那个窗**一直开着**，直到你自己点「关闭」。这就是它存在的理由——「点完就消失，到底装完没有全靠猜」正是上一版的问题。它显示：

- **进度条**：跟着平台报的阶段走（准备 → 下载安装 → 应用配置）。阶段之间的百分比是**估算**的：平台报的是阶段，不是字节数，没有真值可显示。条子只在**真的装完**那一刻才满。
- **一行状态**：此刻在做什么。
- **下载源计数**：这个 profile 配了多个源时，会写明「第 1/2 个源」——换源重试表现为条子**前进**，而不是倒退。
- **已用时间**：秒数一直走，所以你分得清「慢」和「卡死」。万一平台的进度回报迟迟不来，这里也会直说，而不是假装一切正常（安装本身仍在进行）。
- **pnpm 输出**：可展开，就是 pnpm 自己打的那几行。
- **结果**：成功会说「已装到磁盘，重启 DSH 后生效」；失败会把原因和 pnpm 的原话摆出来，并给一个「**重试**」。

**把进度窗关早了也不要紧**：面板顶部会留一条状态（正在更新 / 已更新到 vX / 上次更新失败），点「查看」就能把它叫回来。所以关掉窗口永远只是少看几眼，不会丢掉结果。

> 为什么要写**精确版本号**：刚发布的版本用裸包名可能被 pnpm 的「新版本冷静期」挡住（`ERR_PNPM_MINIMUM_RELEASE_AGE_VIOLATION`），精确版本号会被自动放行。面板里这个更新按钮走的就是精确版本号。

## 九、常见问题

**新任务页上找不到 preset 选择器。**
设置 → 通用 → 打开「**显示代码工作视图**」。

**面板里一个人设都没有。**
先按「刷新」；再确认文件确实在「设置 → 目录来源」显示的那个目录里、后缀是 `.md`、结尾不是 `.off`。

**某一行带「未注册」或「激活失败」。**
「未注册 · 这个 id 被别的所有者占用了」= 这个 id 已经归别人了，改个名字再刷新。「激活失败：…」冒号后面就是原因。

**保存被拒，提示「磁盘上变过」。**
文件在你打开这一行之后被别的程序改过。重开这一行载入最新内容，合并后再保存。旧内容还在 `<id>.md.bak`。

**正文里写 `{{char}}` 为什么不让保存？**
平台的提示词渲染只认 `provider`、`model`、`cwd`，写别的会让整份系统提示词渲染失败——**会话根本起不来**那个级别。面板会拦，Host 还会再拦一次。占位符请用 `[[name]]` / `[[body]]`。

**什么是「公共骨架」？**
一份 `_common.md`，装所有人设共用的条款。写了 `template: _common.md` 的人设只写自己那段，注册时自动拼起来——改一次公共条款，所有人一起变。

**拖不动行，或者一拖就点到按钮了。**
「拖拽排序」默认是关的（防误操作），在「**人设**」工具条打开。开着的时候整行可拖，行内的展开 / 开关 / 导出 / 归档会一起锁住——就是为了不让拖动半路变成误点。关掉立刻恢复。

**装新版本装不上、或装完还是旧版本。**
用**精确版本号**装（如 `dsh-waifu-agents@0.1.3`）。装到磁盘 ≠ 正在运行，重启 DSH 才会换。

**卸载插件会删掉我的人设吗？**
不会。人设是普通文件，在「设置 → 目录来源」显示的目录里。

**卸载之后，这个插件还会留下什么？**
插件自己的东西只有**人设目录**一个（里面有你的 `.md` 和一份 `overrides.json`）。想连它一起清掉：卸载前到「设置」点「**彻底清理**」。另外四样是**平台的**，插件无权删，清理完会列给你：
- `selectedDefault`——安装/改默认时写进 profile 的一行，指向本插件的人设；「彻底清理」会顺手清掉它；
- `.plugin-manager/logs/operation-*`——平台的安装日志，每次装/卸都攒一个；
- pnpm 的内容库索引（`%LOCALAPPDATA%\pnpm`），要自己跑一次 `pnpm store prune`；
- `pnpm-workspace.yaml` 里的 `minimumReleaseAgeExclude` 条目——pnpm 安装时自己写的放行记录，删掉可能让版本被冷静期挡回去，留着更安全。

**我改了名字，文件不见了？**
没丢，文件名跟着名字走了（这就是设计）。
