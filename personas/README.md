# personas/

每个 `*.md` 会被 `dsh-waifu-agents` 注册成一个 agent preset。**文件名就是 preset id。**

> 本文件只讲**目录**和**文件格式**。怎么决定「这次会话用谁」（会话级选择 vs 新会话默认）看包根 `README.md` 的第二节。

本目录是包里自带的出厂人设 + 公共骨架 + 格式说明。**它通常不是你实际在用的人设目录** —— 插件按这个顺序找目录：

1. 行配置里的 `config.dir`；
2. `$DSH_HOME/personas` —— 从环境变量 `DSH_PROFILE_DIR`（形如 `<home>/profiles/<name>`）推出来，**该目录存在时优先用它**；
3. **首次播种**：上面那条路径**不存在**、而 `$DSH_HOME` 推得出来时，`apply` 会把本目录整个拷过去，然后改用它（`dirSource: seeded`）。所以在全新机器上，你编辑的人设落在**你自己的目录**里，而不是 `node_modules` 里那份 —— 后者会在下一次插件升级时被整个覆盖；
4. 以上都不成立，才退回本目录。

想知道这次用了哪一条，看面板「设置 → 目录来源」（`config` / `DSH_PROFILE_DIR` / `seeded` / `package` 之类，界面上显示的是中文说明）。

**播种只新建、从不覆盖**：目标目录只要存在（哪怕是空目录、哪怕里面一个 md 都没有），第 2 条就把它接管了，播种代码根本不会跑。所以本目录里的出厂内容**不会**回头污染你已有的那份人设目录。

## 文件格式

```markdown
---
name: 显示名
order: 13
description: 一句话简介，会显示在人设列表里
group: 组名
template: _common.md
---

正文从这里开始……（只写这个人独有的部分）
```

- id 的规则是 `/^[\p{L}\p{N}][\p{L}\p{N}-]*$/u` —— 首字符必须是字母或数字（**中文也算**，`后藤一里.md` 是合法 id），后面可以跟字母、数字、连字符。
- **一行一个键**，不支持 `>` / `|` 折行；`description` 再长也是**一行**。
- 值的成对引号可有可无；值里出现 `:` 没问题（只按第一个 `:` 切键值）。BOM / CRLF 会自动处理。
- `group:` 只管面板里的分组折叠与组内排序（组内仍按 `order` 排），不影响注册。
- **`template: _common.md`**：正文会被插进 `_common.md` 里 `[[body]]` 的位置，骨架里的 `[[name]]` 会被替换成显示名。**不写这一行，正文就整篇注入**；想单独写全套，把这一行删掉。
- 正文里**不要写 `{{…}}`**：提示词渲染只认 `{{provider}}`、`{{model}}`、`{{cwd}}`，别的变量会让这一行的整份系统提示词渲染失败，会话根本起不来。我们自己的占位符是 `[[name]]` / `[[body]]`。

## 公共骨架：`_common.md`

```markdown
现在起，你是「[[name]]」。

[[body]]

【硬性边界】
- 表演层可以自由发挥；代码、路径、行号、命令参数必须一字不差。
```

- 必须**恰好一个** `[[body]]`：没有、或有两个，保存都会被拒（面板会说明原因）。
- `[[name]]` 可以出现任意次。
- 骨架自己也不许出现非法的 `{{…}}`。
- 保存骨架 → 所有套用它的人设会被重新注册（对新开的对话生效）。

## 本目录文件

| 文件 | 作用 |
|---|---|
| `大肥鱼.md` | 出厂人设：全新机器播种时落到你的目录里；格式参考也是它 |
| `_common.md` | 出厂公共骨架：她（以及所有写了 `template:` 的人设）共用的条款 |
| `README.md` | 本说明 |

`README.md`、`_template.json`、`_common.md` 在**跳过名单**里：不会被注册，也不算异常，而且占不到这些 id。

**能力清单不在这个目录里** —— 它在包根的 `template.json`（20 行工具配置），所有角色共用。想给某个人设加工具，改那一份。
